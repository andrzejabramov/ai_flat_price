# Спецификация проекта: AI_Rielt (Оценка стоимости недвижимости)

## 1. Архитектура и взаимодействие моделей

Система оценки стоимости недвижимости построена на гибридной архитектуре, объединяющей возможности больших языковых моделей (LLM) и классического машинного обучения (Random Forest). Процесс обработки запроса пользователя происходит в несколько этапов:

### Этап подготовительный

- получаем на kaggle.com учебный "грязный" датасет по стоимости квартир в Санкт-Петербурге
- проводим чистку данных и максимально нормализуем их
- обучаем на нескольких (9 шт) моделях
- сравниваем отклонения, выбираем модель
- файлы блокнотов (ipynb) приложены в репо

### Этап 1: Извлечение признаков с помощью LLM (NLP Pipeline)

Пользователь вводит неструктурированное текстовое описание квартиры (например, "евроремонт, тихий двор, рядом с метро, вид на парк").

- **Задача LLM:** Преобразовать неструктурированный текст в структурированные числовые или категориальные признаки.
- **Механизм:** LLM анализирует семантику текста и присваивает баллы или бинарные флаги (например, `renovation_score: 4`, `is_metro_near: 1`, `has_park_view: 1`).
- **Результат:** Вектор дополнительных признаков, который объединяется с базовыми структурированными данными, введенными пользователем (площадь, количество комнат, этаж).

### Этап 2: Предсказание цены с помощью Random Forest

- **Задача:** На основе полного вектора признаков (базовые + извлеченные LLM) рассчитать рыночную стоимость объекта.
- **Механизм:** Обученная модель Random Forest применяет ансамбль решающих деревьев к входным данным, агрегируя их предсказания для получения финальной оценки.
- **Результат:** Итоговая прогнозируемая стоимость, которая отображается пользователю вместе с визуализацией (например, на карте).

## 2. Обоснование выбора модели Random Forest

При разработке системы прогнозирования цены были рассмотрены и протестированы три алгоритма: **Linear Regression**, **Gradient Boosting (XGBoost)** и **Random Forest**.

В качестве финального решения был выбран **Random Forest** по следующим причинам:

### Сравнение с Linear Regression (Линейная регрессия)

- **Проблема LR:** Рынок недвижимости обладает высокой нелинейностью (например, цена растет не линейно с площадью, а есть "премиум" за определенные этажи или виды из окна). Линейная регрессия не способна уловить эти сложные зависимости.
- **Преимущество RF:** Случайный лес по своей природе нелинеен и отлично аппроксимирует сложные взаимосвязи между признаками без необходимости ручного создания полиномиальных фичей.

### Сравнение с Gradient Boosting (XGBoost / LightGBM)

- **Проблема Boosting:** Хотя градиентный бустинг часто показывает метрики (RMSE/MAE) немного лучше, он крайне чувствителен к шуму и выбросам в данных (а в объявлениях о недвижимости их много). Он также требует тщательной и долгой настройки гиперпараметров и склонен к переобучению на небольших выборках.
- **Преимущество RF:**
  1. **Устойчивость к шуму:** За счет бутстрэппинга (случайной выборки с возвращением) и усреднения деревьев, RF гораздо устойчивее к выбросам в цене.
  2. **Интерпретируемость:** RF предоставляет встроенную оценку важности признаков (`feature_importances_`), что критически важно для объяснения пользователю, _почему_ была назначена именно такая цена (например, "на цену сильнее всего повлияла близость к метро и площадь").
  3. **Отсутствие необходимости масштабирования:** В отличие от многих других алгоритмов, RF не требует строгого масштабирования признаков (StandardScaler), что упрощает пайплайн.

**Вывод:** Random Forest обеспечивает оптимальный баланс между точностью предсказания, скоростью обучения, устойчивостью к зашумленным данным и возможностью интерпретации результатов, что делает его идеальным выбором для данной задачи.

## 3. Технологический стек развертывания (Deployment)

- **ОС и виртуализация:** Proxmox VE, LXC-контейнер (Debian 12) для минимального потребления ресурсов (~300 МБ RAM).
- **Контейнеризация:** Docker (изоляция зависимостей Python и Streamlit).
- **Backend/Frontend:** Python 3.11, Streamlit (интерфейс), Scikit-learn (ML), Joblib (сериализация модели).
- **Сеть:** Port Forwarding на уровне роутера для обеспечения доступа к приложению по публичному IP-адресу.
